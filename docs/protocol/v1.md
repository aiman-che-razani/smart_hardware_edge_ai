# SentinelDAQ protocol V1 (implemented)

All multibyte values are little-endian; signed integers use two's complement.
Both the binary and CSV Uno builds use 115200 baud, 8N1, one report/second.
The CSV build cannot be used with the binary acquisition command.

## Frame

| Offset | Field | Size |
|---|---|---|
| 0 | Magic A5 5A | 2 |
| 2 | Version = 1 | 1 |
| 3 | Type | 1 |
| 4 | Payload length, 0–40 | 1 |
| 5 | Payload | length |
| 5+length | CRC16 | 2 |

CRC-16/CCITT-FALSE: polynomial 0x1021, init 0xFFFF, refin/refout false, xorout 0.
Coverage is version/type/length/payload; magic and CRC are excluded. CRC for ASCII
`123456789` is 0x29B1. No end marker or escaping: length and CRC delimit a frame.
On invalid header/CRC, discard one byte and scan again. Incomplete frames expire
after a 500 ms inter-byte timeout. A plausible false length can delay recovery
until its bounded frame size or timeout; there is no infinite accumulation.

## Types and payloads

| Type | Number | Payload |
|---|---|---|
| DATA | 1 | 29 bytes, table below |
| STATUS | 2 | boot u32, report_interval u16 ms, ultrasonic_interval u16 ms, ambient_interval u16 ms |
| ACK | 3 | command_id u16, command_type u8, result u8 |
| ERROR | 4 | error_code u8 |
| SET_ALARM | 16 | command_id u16, value u8: 0 NORMAL, 1 WARNING, 2 FAULT, 3 UNKNOWN |
| CLEAR_ALARM | 17 | command_id u16, reserved u8=0 |
| START_STREAM | 18 | command_id u16, reserved u8=0 |
| STOP_STREAM | 19 | command_id u16, reserved u8=0 |
| PING | 20 | command_id u16, reserved u8=0 |
| GET_CONFIG | 21 | command_id u16, reserved u8=0; ACK plus STATUS |

ACK result: 0 success, 1 invalid value, 2 unsupported operation. Malformed command
payload length produces ERROR code 3 when TX space permits. Bad CRC is discarded;
it is never executed. Firmware replies are best effort in a bounded UART buffer;
lost ACKs are handled by host retries. STATUS repeats approximately each second.
Host skips unknown message types and counts parser errors. Host invalid DATA/STATUS
lengths are counted. ERROR packets are diagnostic, not valid samples.

## DATA fields, offsets within payload

| Offset | Field | Encoding |
|---|---|---|
| 0 | boot ID | u32 |
| 4 | sequence | u32 |
| 8 | timestamp_ms | u32, host-assembly `millis()` time |
| 12 | distance | u16 mm, HC-SR04 last valid reading |
| 14 | distance age | u16 ms, saturates at 65535 |
| 16 | water level raw | u16, 0–1023 ADC counts |
| 18 | thermistor raw | u16, 0–1023 ADC counts |
| 20 | light raw | u16, 0–1023 ADC counts |
| 22 | ambient temperature | i16, 1/10 °C (DHT) |
| 24 | ambient humidity | u16, 1/10 %RH (DHT) |
| 26 | ambient age | u16 ms, saturates at 65535 |
| 28 | flags | u8 |

Flags: bit 0 distance valid, bit 1 ambient (DHT) valid, bit 2 DHT checksum error.
Remaining bits reserved — commented in `types.h` as unused placeholders for the
deferred stepper/IR receiver, not currently populated. Invalid raw values must
not be interpreted as valid zeros. Water-level/thermistor/light raw values are
uncalibrated ADC counts; unit conversion happens host-side in `pipeline.py`.
Slow/analog samples are latest values, not synchronized to one instant.

Frame is 36 bytes, sent once per second: roughly 40-50 bytes/s including the
STATUS frame — trivial against 115200 baud's ~11520 bytes/s capacity. Timestamp/
sequence wrap modulo 2^32. Sequence increments once per assembled report even if
serial TX drops it.

Boot ID is an EEPROM counter; EEPROM location 0–3 is reserved. Torn power-loss
writes and finite endurance mean it is not a globally unique identity. Physical
reconnect creates an explicit session boundary on the host even if boot ID repeats.
Do not repeatedly reset as a high-frequency stress test; investigate wear-levelled
session generation before a deployment requiring frequent resets.

## Commands and failure behavior

One host command in flight, 16-bit ID, 500 ms ACK timeout, at most three attempts
per transaction. ID and type must both match. Retry bytes are identical. Set/clear/
start/stop are naturally idempotent; firmware does not keep an unbounded history.
After a failed transaction the control loop may issue a fresh transaction to
reconcile desired state. On reconnect queued commands are discarded and current
configuration/state is established again. Hardware FAULT latches on host loss.

CSV V0 is `D,boot,sequence,timestamp_ms,distance,distance_age,water_level,thermistor,
light,ambient_temp,ambient_humidity,ambient_age,flags` with decimal integers and
LF/CRLF. Host bounds a line to 160 bytes and recovers at newline. CSV parser/display
is read-only; binary transport is used for full DAQ.
