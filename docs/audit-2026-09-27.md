# Audit ledger, 2026-09-27

Seven audits were run on this repository on 2026-09-27: **security**,
**architecture**, **database**, **API/protocol**, **code-style**, **design-system**
(the React frontend) and **product/evidence** (do the docs match the recorded
evidence). This is the findings-and-status ledger, updated after the fixes were made
the same day. Severity is a triage judgement, not a scored rating.

Status values: `fixed in code`, `fixed in docs`, `open — needs hardware`,
`open — decision`, `not changing (reason)`.

**Verification behind "fixed in code":** the Python test suite went from 58 to 79
passing tests (`tests/test_storage.py`, `tests/test_api.py` and additions to
`tests/test_integration.py`); both firmware environments were compiled (`uno`,
`uno_csv`) but **nothing was flashed or run on hardware**; the frontend was built
(`npm run build`) but **not viewed in a browser**; the API was exercised live on a
copy of the demo data (foreign Host header refused, Range header served normally on
the patched Starlette).
